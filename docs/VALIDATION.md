## Перед публикацией

Локальный `.env` содержит только вновь сгенерированные секреты для этого экземпляра. Он исключён из Git и не должен попадать в архив или публичный репозиторий. Не публикуйте `.venv`, `node_modules`, `data`, журналы, резервные копии или историю исходного проекта. Для конфигурации распространяйте только `.env.example`.

Подключение модели и поиска требует собственных HTTP-адаптеров. По умолчанию модель работает в демонстрационном режиме, база знаний пуста. Полное развёртывание, доставка почты и push, а также реальные провайдеры требуют отдельной проверки после настройки.

До публичного распространения подтвердите права на производный код и проверьте лицензии зависимостей.
