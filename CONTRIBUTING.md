# Участие в разработке

Для изменений создайте ветку своего форка. Сначала воспроизведите ошибку тестом, затем выполните `npm test`, `npm run build` и Python-тесты. Не включайте пользовательские данные в fixtures: используйте домены `example.test` и искусственные вопросы.

При изменении ролей, маршрутизации, обсуждения и доставки добавляйте проверки прав, повторных запросов и недоступности черновика сотруднику. Адаптеры должны иметь тесты без реальной отправки данных внешнему провайдеру. UI проверяйте на desktop и ширине 390px.
